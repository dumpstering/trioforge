# Changelog

## Unreleased

- The first milestone preview: the Paladin / Monk / Berserker page, with the best kit for each race, role and tier, and the rules, sources, about and changelog pages.
- Every page shows the data date and the game patch it was built from. Data releases are named `data-YYYY-MM-DD`; each one will be listed here with a link to its report of changed picks.
- Rewards of quests whose wiki page links to the page of a live zone under the name of the test, such as the Plane of Sky class tests, now count as a live source when the item has no other live source: 99 items that were hidden for lack of one are graded wiki.
- Every strict or wiki item that can be worn now has a page of its own (`/item/<key>/`): its stats at every tier from +0 to +10, the damage and delay of a weapon, where it comes from, how sure we are that it exists in EverQuest Legends, the trios whose default answer wears it and the credit to the wiki page it was read from. The names in the kit of a trio page and the items on the sources page link to them.
- The home page has a search box: type three classes in any order, with the codes (pal mnk ber) or the full names (paladin monk berserker), and it offers the page of the trio or says that the trio is coming soon. The page of every trio is also a plain link on the home page, which works without JavaScript.
- An address of a trio with the classes in another order, in capitals or without the last slash (such as /trio/ber-mnk-pal) now takes you to the page of the trio, keeping its query and a shared-kit link. The page for an address that leads nowhere says where to look when an item or a trio has no page. A link in another order that is shared in a chat still previews as "Not found", since the preview does not run the script.
- A link to a trio page pasted into the search box opens that page, with its query and its shared kit kept, in whatever order of the classes it was written; any other address says to open it in the address bar. A two-word class such as shadow knight is no longer called a mistake while it is being typed.
