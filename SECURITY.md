# Security policy

## Reporting a problem

Report a security problem through a **private GitHub security advisory**: open the repository's Security tab and choose "Report a vulnerability". Please do not open a public issue for it.

If you find a character name, a player name or text from a game log in this repository or in its history, report it the same way. A public issue that quotes it would spread it further.

## What there is to attack

There is no server. TrioForge is a set of static files, and everything a visitor enters is parsed in the browser. There are no accounts, and nothing a visitor enters is sent anywhere.

TrioForge is a fan project that is maintained in spare time, so replies are best-effort.
